# Barrão Auto Elétrica — Etapa 1

Site inicial com carro esportivo estilizado 3D, React, TypeScript e Tailwind.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicação

Importe o repositório na Vercel (framework Vite; build `npm run build`; saída `dist`).

**Atenção:** esta é somente a etapa 1. Loja, agendamento e painel ainda não foram implementados. Nenhuma chave secreta deve ser colocada no frontend.
